# git5sec12 — Welcome Page

This project now includes a simple welcome page.

Files added:

- `index.html` — the welcome page
- `styles.css` — minimal styling

To view locally, open `index.html` in your browser, or run a local HTTP server from the project root.

PowerShell (Python 3 required):

```powershell
python -m http.server 8000

# Then open http://localhost:8000 in your browser
```
